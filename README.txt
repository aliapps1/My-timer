ALIAPPS1 WEBSITE PACKAGE

Files:
- index.html: Main Aliapps1 homepage
- styles.css: Responsive design
- script.js: English/Arabic language switch and animations
- focus-champion/index.html: Focus Champion page
- global-task-planner/index.html: Global Task Planner page
- privacy/index.html: Privacy policy
- terms/index.html: Terms

DEPLOYMENT TO GITHUB
1. Open the My-timer repository.
2. Upload all files and folders from this package to the repository root.
3. Do not delete the CNAME file if GitHub created one for aliapps1.store.
4. Commit the changes.
5. Wait 1-3 minutes and refresh https://aliapps1.store

IMPORTANT
- Replace the # link on the Focus Champion Google Play button with the actual Google Play URL.
- Keep any existing app-ads.txt file. This package does not include it because your AdMob publisher ID was not provided.
