🔔 Notification & Alarm Setup Guide

Ensure you hear the timer alarm even when your phone is locked or you're in another app

📱 Android Settings (Chrome)

Step 1: Grant Notification Permission

  1. When you start the timer for the first time, you'll see: "Allow notifications?"
  2. Click "Allow"
  3. If you accidentally clicked "Block", follow the manual steps below

Step 2: Manual Notification Setup (if blocked)

  1. In Chrome, click the lock icon 🔒 next to the website URL
  2. Find "Notifications"
  3. Set it to "Allow"
  4. Refresh the page

Step 3: Android System Settings

  1. Settings > Apps > Chrome
  2. Notifications > Make sure it's ON
  3. Battery > Select Unrestricted
  4. Turn off Do Not Disturb or exempt Chrome from it
⚠️ Important Notes:
  • Turn on phone sound (not Silent Mode)
  • Increase Media Volume
  • If you installed the PWA, go to Settings > Apps > Focus Timer and enable notifications

🍎 iOS Settings (Safari)

Step 1: Install PWA

  1. Open the website in Safari
  2. Tap the Share button (square with arrow)
  3. Select "Add to Home Screen"
  4. Open the app from your Home Screen (not Safari)

Step 2: Notification Permissions

  1. Settings > Notifications
  2. Find Focus Timer
  3. Enable Allow Notifications
  4. Make sure Sounds is enabled
  5. Enable Lock Screen and Banners
⚠️ iOS Limitation:

Unfortunately, iOS doesn't allow web apps to play sound in the background. For best results:

  • Keep the app open
  • Or convert it to a native app (for App Store)

🔧 Technology Used

✅ The app uses 5 different methods for notifications:

  1. Web Notifications API: System notifications that show even when app is closed
  2. HTML5 Audio: External audio file played at maximum volume
  3. Web Audio API: Custom generated sound (3 different tones)
  4. Vibration API: Phone vibration (Android only)
  5. Wake Lock API: Prevents screen from turning off
🔍 How It Works:

When the timer completes:

  • ✅ Shows 5 consecutive notifications (one every 4 seconds)
  • ✅ Plays sound 5 times (every 2 seconds)
  • ✅ Phone vibrates 3 times
  • ✅ Sound continues for 10 seconds
  • ✅ Notifications appear on lock screen

❓ Troubleshooting

🔇 No Sound:

  • Check device volume (Media Volume, not Ring Volume)
  • Turn off Silent Mode or Do Not Disturb
  • In app settings, set sound to "Soft Chime" (not "No Sound")
  • Check the mute button 🔇 in the app

🔕 No Notifications:

  • Make sure you clicked "Allow" for notification permission
  • Check browser and system settings (above)
  • Refresh the page
  • Clear browser cache

📱 Only Works When App is Open:

  • Install the PWA (Add to Home Screen)
  • Enable Background permissions
  • Set Battery Optimization to Unrestricted

✅ Final Checklist

  • ☐ Granted Notification permission
  • ☐ Phone volume is on
  • ☐ Silent Mode is off
  • ☐ Do Not Disturb is off
  • ☐ Battery Optimization: Unrestricted
  • ☐ PWA installed
  • ☐ Tested and working ✅
